# DESIGN.md — Review Rescue

## Brand Direction

Approachable. Calm. Trustworthy. Fast.

Review Rescue should feel like a competent assistant quietly handling something stressful — not a strategic consulting tool. It is a standalone product, distinct from Erica Kelly Consulting's premium brand system, with a light credibility tie-in rather than a shared visual identity.

## Core Palette

### Background & Text

- Warm White — `#FAFAF7` — default page/app background  
- Deep Slate — `#2B2E33` — primary text, headings

### Status Colors

- Trust Green — `#2E8B6F` — positive actions, resolved/sent states  
- Alert Amber — `#E8A33D` — needs-attention, pending escalation  
- Soft Red — `#D9534F` — sensitive/at-risk items only; use sparingly, never for routine states

### Neutrals

- Mid Gray — `#8A8F98` — secondary text, timestamps, metadata  
- Light Gray — `#EEEFF1` — borders, dividers, card backgrounds

## Typography

- **Single typeface:** Inter (or Nunito Sans as fallback) for both headings and body — no separate heading/body pairing needed at this scale.  
- Headings: weight 600–700  
- Body: weight 400–500  
- Prefer sentence case throughout; avoid all caps except small labels (e.g., status tags).

## Type Scale

- H1 / Page title: 28–32px  
- H2 / Section header: 20–22px  
- Body: 15–16px  
- Caption / metadata: 12–13px

## Spacing

Use an 8-point grid. Favor generous whitespace over dense layouts — this is a tool used quickly, often on a phone, often under time pressure.

## Layout Rules

- Mobile-first; most usage will be a quick glance-and-respond on a phone.  
- One primary action visible per screen (e.g., "Send," "Edit," "Regenerate").  
- Cards for individual reviews; simple list view for history.  
- Corner radius: 10–12px.  
- Shadows: subtle only.

## Tone of Interface Copy

Short, plain, reassuring. No jargon, no manufactured urgency.

**Do:** "New review from Maria — here's a draft." **Don't:** "Action required: review sentiment alert."

Status labels should be calm and human: "Needs your reply," "Sent," "Needs personal attention" (for escalations) — not alarm-toned system language.

## Credibility Line

Include in the app footer and any marketing/landing pages:

**"Review Rescue — an Erica Kelly Consulting company"**

Small, unobtrusive, consistent placement. This carries trust from EKC into Review Rescue without borrowing EKC's full visual identity.

## What to Avoid

- EKC's Midnight Ink / Cobalt executive palette (reserved for consulting-brand materials)  
- Dense dashboards or data-heavy layouts  
- Corporate or "strategic transformation" language  
- Anything that reads as high-stakes or alarming for routine, positive reviews
